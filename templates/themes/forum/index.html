CRust — 모던 웹의 새로운 기준

CRust는 Rust 언어의 타협 없는 초고속 실행 속도와 무결점 메모리 안전성(Memory Safety), 강력한 비동기 동시성 처리를 극대화한 모던 단일 바이너리 웹 프레임워크입니다. 가비지 컬렉터(GC) 지연이나 복잡한 런타임 없이, 단 하나의 실행 파일로 고성능 커뮤니티와 포럼, 웹 서비스를 번개처럼 가동하세요.

시작 가이드 (Getting Started) 커뮤니티 참여하기 공지사항 GitHub 저장소

왜 CRust인가요? (Key Highlights)

단일 바이너리 & 초경량 메모리

Nginx, PHP-FPM 없이 cargo run 한 번으로 즉시 가동. 메모리 점유율 30~50MB 수준으로 저사양 VPS에서도 날아다닙니다.

SQLite WAL & FTS5 고속 검색

별도 DB 서버 세팅 없이 파일 하나로 0초 자동 세팅! SQLite FTS5 전문검색 내장으로 수십만 건 게시물도 0.001초에 탐색합니다.

동적 테마 & 파일 기반 라우팅

직관적인 모듈형 아키텍처! FTP로 폴더만 복사하면 테마 즉시 추가, page/about.html 넣으면 /page/about으로 자동 렌더링됩니다.

엔터프라이즈 보안 기본 탑재

Argon2id 비밀번호 해싱, CSRF 자동 방어, Ammonia XSS 차단, 1~10단계 권한 관리 및 영속 세션 엔진이 안전을 보장합니다.

실시간 SSE 알림 & EventBus

댓글, 쪽지, 추천, 포인트 변동이 브라우저 새로고침 없이 Server-Sent Events(SSE)로 실시간 전달됩니다.

글로벌 다국어(i18n) & 다크모드

한국어, 영어, 일본어, 중국어 4개국어 원클릭 언어팩 내장. 시스템 설정 감지 기반 라이트/다크모드가 기본 제공됩니다.
