0 서버 최저 사양 & Ubuntu 기본 세팅

CRust는 컴파일된 뒤 실행 시 메모리를 약 15~30MB만 사용하므로 아주 저렴한 저사양 서버에서도 쾌적하게 운영할 수 있습니다. (단, 서버에서 직접 소스를 빌드할 때는 아래 기본 패키지와 충분한 메모리/스왑이 필요합니다.)

운영 최저 · 권장 사양

  • OS: Ubuntu 20.04 / 22.04 / 24.04 LTS 권장 (Debian, Rocky 등 Linux 전반 지원)
  • CPU: 1 vCPU 이상 (빌드 시 2 vCPU 이상 권장)
  • RAM: 운영 최소 512MB / 빌드 시 2GB 이상 (또는 Swap 2GB)
  • Disk: 여유 공간 5GB 이상 (툴체인 + 빌드 캐시 포함)

네트워크 · 포트 안내

  • 내부 앱 포트: 기본 3000 (config.toml에서 변경 가능)
  • 외부 서비스: Nginx / aaPanel / Caddy로 80, 443(HTTPS) 리버스 프록시 연결
  • DB 서버: 별도 MySQL/MariaDB 설치 불필요 (SQLite 내장)
# 1. Ubuntu 필수 빌드 패키지 설치 (C 컴파일러, OpenSSL, SQLite 헤더 등)
sudo apt update && sudo apt install -y build-essential pkg-config libssl-dev libsqlite3-dev git curl

# 2. Rust (rustup & cargo) 설치 및 환경변수 적용
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# 3. (선택) RAM 1GB 이하 저사양 VPS에서 직접 빌드 시 2GB Swap 추가
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile

1 저장소 복제 & 초고속 빌드

CRust는 Nginx, PHP-FPM, 외부 DB 서버 없이도 실행 파일 하나로 구동되는 단일 바이너리(Single Binary) 구조입니다.

# 1. 저장소 복제 및 이동
git clone https://github.com/1clickmake/CRust.git crust
cd crust

# 2. 설정 파일 복사
cp config.example.toml config.toml

# 3. 릴리즈 빌드 및 실행
cargo run --release
💡 제로 컨피그(Zero-Config) 자동 설치:
별도의 웹 인스톨러 마법사 없이, 서버가 실행될 때 SQLite DB(rust_board.db) 및 필수 테이블, 기본 게시판(notice, free), 최고관리자 계정이 0.1초 만에 자동 생성됩니다.
• 기본 관리자 계정: admin / admin1234

2 aaPanel 연동 (리버스 프록시, SSL, 데몬 등록)

aaPanel 환경에서는 마우스 클릭 몇 번으로 Nginx 역방향 프록시와 무료 HTTPS(Let's Encrypt), 백그라운드 무중단 실행(Supervisor)을 구성할 수 있습니다.

웹사이트 등록

  • aaPanel ➔ [Website] ➔ [Add site]
  • Domain: crust.cmake.work
  • Website path: /www/wwwroot/crust
  • Database: None / PHP: Pure

역방향 프록시 설정

  • 사이트 [Settings] ➔ [Reverse Proxy]
  • Target URL: http://127.0.0.1:3000
  • Proxy Directory: / (기본값)
  • Sent Domain: $host

무료 HTTPS (SSL)

  • 설정 창 좌측 [SSL] 탭 클릭
  • [Let's Encrypt] 선택 ➔ 도메인 체크 ➔ [Apply]
  • 발급 후 [Force HTTPS] 토글 스위치 ON!

Supervisor 무중단 데몬

  • aaPanel ➔ [App Store] ➔ Supervisor 무료 설치
  • Command: /www/wwwroot/crust/target/release/rust_board
  • Run Dir: /www/wwwroot/crust / User: root

3 나만의 테마 추가 & FTP 실시간 커스텀

CRust는 그누보드처럼 폴더 단위로 테마를 관리합니다. 복잡한 컴파일 없이 FTP로 폴더만 복사해 넣으면 끝납니다.

새 테마 생성 3단계

  1. templates/themes/default/ 폴더를 복사하여 templates/themes/my_theme/ 폴더를 생성합니다.
  2. 안에 있는 theme.toml 파일을 열고 테마 이름, 설명, 버전을 수정합니다: 
    name = "내 전용 테마"
slug = "my_theme"
version = "1.0.0"
author = "두목님 & 아사미야 💕"
description = "초고속 반응형 커스텀 테마"
  3. 관리자 페이지(/admin/themes)에 접속하면 새 테마가 자동 인식되어 목록에 뜹니다. [활성화] 버튼을 누르면 서버 재시작 없이 즉시 디자인이 교체됩니다!
✨ 스마트 템플릿 Fallback 지원:
새 테마에 모든 HTML을 다 만들 필요가 없습니다. 내가 수정하고 싶은 페이지만 넣어두면, 없는 파일은 default 테마에서 자동으로 빌려와서 안전하게 렌더링합니다.

4 파일 기반 동적 페이지 추가 (/page/{이름})

DB 등록 없이 FTP로 page/ 폴더에 .html 파일만 넣으면 웹페이지가 즉시 생성됩니다.

예시: 회사소개 페이지 만들기

templates/themes/forum/page/about.html 파일을 생성하고 아래처럼 작성합니다: 

{% raw %}{% extends layout_tpl %}

{% block title %}회사 소개 · {{ site_title }}{% endblock %}

{% block content %}


    
회사 소개

    
CRust 기반으로 제작된 초고속 비즈니스 플랫폼입니다.



{% endblock %}{% endraw %}

👉 접속 주소: https://crust.cmake.work/page/about

• 상단 네비게이션, 헤더, 다크모드/라이트모드, 다국어 전환 기능이 자동으로 완벽 상속됩니다.
• 순수 HTML 단독 페이지가 필요할 경우 static/ 폴더를 활용할 수도 있습니다.

5 데이터베이스(DB명/유저/패스워드) & 환경설정 관리

CRust의 데이터베이스 및 핵심 환경 설정은 루트 디렉토리의 config.toml 파일 하나로 간편하게 제어합니다.

1. 데이터베이스 명(파일명) 변경 방법

현재 기본 내장된 SQLite는 서버 없이 파일 하나가 곧 데이터베이스입니다. config.toml의 url 항목에서 파일명을 원하는 대로 변경할 수 있습니다:

[database]
# 기본값: sqlite://rust_board.db?mode=rwc
url = "sqlite://my_community.db?mode=rwc"
max_connections = 10
  • 신규 생성: 새 파일명으로 바꾸고 프로세스를 재시작하면, 그 이름으로 빈 DB와 기본 데이터가 0.1초 만에 자동 생성됩니다.
  • 기존 데이터 유지: 서버 터미널에서 mv rust_board.db my_community.db 로 파일명을 변경한 뒤 config.toml을 수정하시면 기존 글과 회원이 100% 그대로 유지됩니다.

2. 관리자 패스워드 & 계정 정보 변경 방법

방법 A: 웹 화면에서 즉시 변경 (권장)

1. /member/login 에 초기 계정(admin / admin1234)으로 로그인
2. 마이페이지(내 정보 수정) ➔ 비밀번호 변경 클릭
3. 새 비밀번호를 입력하면 초강력 Argon2id 해시로 암호화되어 안전하게 변경됩니다!

방법 B: 소스코드 초기 시드 변경

첫 배포 시 자동 생성되는 계정 자체를 바꾸고 싶다면, src/db.rs 33~42번째 줄의 "admin"과 "admin1234"를 원하는 기본값으로 수정한 뒤 빌드하면 됩니다.

3. MySQL / MariaDB (유저명, 패스워드, DB명) 연결 포맷

aaPanel 등에서 MySQL/MariaDB 데이터베이스를 생성하여 연결하고자 할 경우, 아래 형식의 표준 Connection String을 config.toml에 지정할 수 있습니다:

[database]
# 포맷: mysql://유저명:패스워드@호스트주소:포트/데이터베이스명
url = "mysql://crust_user:mypassword123@127.0.0.1:3306/crust_db"

※ 대규모 서비스 확장을 위해 MySQL 또는 PostgreSQL 드라이버를 활성화할 때 동일한 방식으로 간편하게 유저명과 패스워드를 지정할 수 있습니다.

[server]
host = "127.0.0.1"
port = 3000
dev_mode = false # true 설정 시 템플릿(HTML) 수정 즉시 새로고침 반영

[storage]
driver = "local" # local 또는 s3 (Cloudflare R2 / AWS S3 지원)
upload_dir = "uploads"
max_file_size_mb = 20
• 백업 & 복원: SQLite 파일(rust_board.db) 하나만 복사해두면 완벽한 백업이 완료됩니다.
• 설정 반영: config.toml 파일 수정 후에는 aaPanel Supervisor에서 프로세스를 한 번만 [Restart] 해주시면 적용됩니다.
